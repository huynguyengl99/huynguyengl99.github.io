Practices for Both Services

The architecture is no use if the code inside each service is sloppy.

Business side
  • authorize in two layers
  • a serializer per action
  • enums default to safe
  • a union the frontend can exhaust
  • settings safe by default
Agent side
  • agents built per request
  • tracing before the first call
  • log the silent failures
