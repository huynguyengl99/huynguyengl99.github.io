Split the Services, and Know Where the Line Goes

Draw the line at state ownership, not at anything that sounds like a layer.

Backend owns
  • the record
  • what a reload needs
  • auth and tickets
Agent owns
  • execution state
  • while a run is in flight
  • graphs and tools
agent → backend  updates travel one way
