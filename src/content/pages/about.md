Hi, I'm Huy Nguyen — a senior full-stack software engineer based in Vietnam.

I build products end to end: Python backends with Django/DRF and FastAPI, React + TypeScript frontends, and the cloud infrastructure underneath them (GCP, Kubernetes, Terraform). These days a big part of my work is designing AI agent systems — LLM orchestration, realtime and voice pipelines, and the observability to keep them honest in production.

## Open source

I maintain a number of Python packages, mostly around the Django and ASGI ecosystem:

- [chanx](https://github.com/huynguyengl99/chanx) — batteries-included WebSocket framework for Django Channels, FastAPI, and ASGI apps, with Pydantic validation and AsyncAPI docs
- [fast-channels](https://github.com/huynguyengl99/fast-channels) — Django Channels-style consumers and channel layers for FastAPI/Starlette
- [drf-auth-kit](https://github.com/huynguyengl99/drf-auth-kit) — modern DRF authentication with JWT cookies, social login, and MFA
- [django-headless-cms](https://github.com/huynguyengl99/django-headless-cms) — headless CMS on Django with versioning, multi-language content, and auto-translation
- [nplus1](https://github.com/huynguyengl99/nplus1) — N+1 query detector for Django ORM, SQLAlchemy, and Peewee

You can find the rest on [my GitHub](https://github.com/huynguyengl99).
